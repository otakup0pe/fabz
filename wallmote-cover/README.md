# Aeotec WallMote Quad "Molly Guard"

_This file is still under active development; I am trying to get the print-in-place hinges correct._

Prevents accidental interaction with the [WallMote](https://aeotec.com/products/aeotec-wallmote-quad/), and provides an easy way to label buttons. The OpenSCAD file was created with some assistance from a cursed computer hallucination. I make use of the resulting device to protect infrastructure related smart switches. The single included STL file works for me, you may need to tweak parameters.

* Text label, font, size  provided as per-cover parameters.
* Parameters for adjusting tightness of fit.
* Parameters to adjust "tabs" which are used to access the doors.
